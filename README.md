# homebrew-localtools

Homebrew tap for [localtools](https://tools.chaitanyaprabuddha.com): free offline tools that run on your machine.

```sh
brew tap chayprabs/localtools
brew install localtools-<tool>
```

or in one step: `brew install chayprabs/localtools/localtools-<tool>`. Works on macOS (Apple Silicon and Intel) and Linux.
Run `localtools-<tool>` to start it in your browser. Update with `brew upgrade`, remove with `brew uninstall localtools-<tool>`.

Formulae are generated from the localtools release manifest; please report problems at
https://github.com/chayprabs/localtools/issues.
